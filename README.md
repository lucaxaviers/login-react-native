# ✈️ Travel Login — React Native Mobile UI

[![React Native](https://img.shields.io/badge/React_Native-0.73-61DAFB?style=for-the-badge&logo=react&logoColor=black)](https://reactnative.dev/)
[![Expo](https://img.shields.io/badge/Expo-50-000020?style=for-the-badge&logo=expo&logoColor=white)](https://expo.dev/)
[![React Native Paper](https://img.shields.io/badge/React_Native_Paper-4.9-6200EE?style=for-the-badge&logo=materialdesign&logoColor=white)](https://callstack.github.io/react-native-paper/)

Interface mobile de login moderna e imersiva com temática de viagens (*"Traveling around the world"*), desenvolvida em **React Native** com **Expo** e componentes **React Native Paper**.

---

## ✨ Destaques de UI/UX

- 🖼️ **Fundo Imersivo:** Uso de `ImageBackground` em tela cheia com overlay suave para maximizar o apelo visual.
- 🔘 **Inputs Arredondados:** Campos customizados (`TextInput`) com bordas curvas, contraste de texto branco e feedback tátil.
- 🔒 **Segurança Visual:** Campo de senha protegido com `secureTextEntry={true}`.
- 💾 **Lembrar de Mim:** Gerenciamento do estado de persistência através do hook `useState`.
- 📱 **Mobile First:** Totalmente adaptado para diferentes proporções de tela através de `SafeAreaView` e `StyleSheet`.

## 🚀 Como Executar

```bash
# Clonar o repositório
git clone https://github.com/lucaxaviers/login-react-native.git

# Acessar a pasta do app
cd login-react-native/App-Login

# Instalar pacotes
npm install

# Rodar com Expo
npx expo start
```
