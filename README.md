## ✨ Recursos de Interface

- 🌄 Fundo fotográfico imersivo (`ImageBackground`).
- 🔘 Inputs estilizados com cantos arredondados e contraste claro.
- 🔒 Campo seguro de senha (`secureTextEntry`).
- 💾 Alternador de estado "Lembrar de Mim" (`useState`).

---

## 🚀 Como Executar

```bash
# Clonar o repositório
git clone https://github.com/lucaxaviers/login-react-native.git

# Acessar a pasta
cd login-react-native/App-Login

# Instalar dependências e rodar
npm install
npx expo start
```
